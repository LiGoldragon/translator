# translator, version 1

The translator library every Nexus's translator shares, written once: the
place a Nexus starts in and the sockets named under it, the caller of a
connection, the framing of Signal, the text sockets and their serving, the CLI,
the hook socket and its client, the emission socket with a lasting emission, and
the running of a program. A Nexus's translator is this library with its name and
the words of its own calls (vision nexus 1).

This is the `next` branch of the repository, version 1.0.0: the translator
rewritten whole, lifted from the synchronous translator of the experiment
`claude-harness-nexus` (its `transport` and `claude-harness-translator` crates,
at b06ff40), its history starting from the experiment's and sharing none with
`main`. `main`, 0.5.3, stays as it is for its users, who move to this version as
one change. It takes nothing from the tokio serving crate and no actor library:
every connection is a thread and a Unix socket.

| crate | holds |
|---|---|
| `translator-transport` (`transport/`) | `Place`, `Named`, `Placed`: the place and the sockets and files named under it; `Caller`, read from the kernel's peer credentials; `Framed`, the length-prefixed rkyv frames; `EmissionSocket` and `Held`: the emission socket as the Nexus holds it, with `Unobserved`. What a Nexus program takes. |
| `translator` (`translator/`) | `Translator`: the sockets and the serving of each (`text`, `hooks`, `emissions`, `listening`); `Calling` and `Hooking`: the CLI and the hook client, written once; `Lasting`, `Lasted`, `Growth`: a lasting emission and the file follow by inotify; `run` and `capture`: running a program; `Translatable`. Re-exports the transport. What a Nexus's translator takes. |
| `relay-signal`, `relay-nexus`, `relay-translator` | the Relay Nexus, the proof of concept below |

The ethos of the library is in `transport/ethos/` and `translator/ethos/`.

## What a Nexus's translator is made of

```rust
// the whole of a Nexus's CLI, and its hook client
fn main() -> ExitCode { RelayTranslator::call(TextSocket::Ordinary).into() }
fn main() -> ExitCode { RelayTranslator::hook() }

// its translator: a lane for each socket, then the word that it listens
let mut translator = Translator::<RelayTranslator>::from_arguments()?;
translator.prepare()?;
translator.text::<Input, Call, Output>(Placed::TextSocket, Placed::NexusSocket, ETHOS, |caller, input| Call { caller, input })?;
translator.hooks::<Hook, Call, Output>(|caller, hook| Call { caller, input: Input::Report(hook) })?;
translator.emissions::<Emission>()?;
translator.listening::<Call, Output>(&Call { caller: Caller::itself()?, input: Input::Listening });
translator.serve();
```

What the Nexus's translator writes by hand is the words: `Translatable<T>` for a hook's payload, the
body of each emission (`Emittable<T>`, generated by ethos-zero beside the emissions), `Lasting<T>` for
each emission that lasts, and `Emitting<T>`, the match from the emission enum to those bodies. `T` is
the translator's own marker type, so that every body lives in the translator's crate and not the
contract's.

A Nexus program holds the place and the emission socket, and no text:

```rust
let emissions = EmissionSocket::of::<Relay>(&place);
emissions.send::<Emission, Outcome>(&Emission::Command(command))   // Result<Outcome, Unobserved>
emissions.hold::<Emission, Outcome>(&Emission::Follow(follow))     // Result<Held<Outcome>, Unobserved>
```

## The Relay Nexus, its proof of concept

The smallest Nexus that shows the library, high level and low. Its contract is two ethos files in
`relay-signal/ethos/`, a Signal and an Emission, both checked by ethos-zero 31 (48f155d, branch
process-root) and generated by it into `relay-signal/src/generated/`; the `ethos` check of the flake
regenerates them and fails on any difference.

```sh
relay-nexus '{ main /run/user/1000/nexus/main /home/example/.local/state/nexus/main }'
relay-translator '{ main /run/user/1000/nexus/main /home/example/.local/state/nexus/main }'
# ~/.config/nexus/relay-nexus.datom is { main }
relay 'Run.{ «/bin/sh» [ «-c» «echo hello» ] }'    # Ran.Done.«hello\n»
relay 'Follow.{ «/tmp/transcript» 0 16 }'          # Following
relay 'Seen'                                       # Noticed.[ Lined.first Lined.second ]
echo 'Started alpha' | relay-hook                  # Seen: Hooked.Started.alpha
relay                                              # no datom: the Ethos of its Signal
```

- **The text socket and the CLI.** `relay` is `RelayTranslator::call`, one line; the translator's
  `text` lane reads each datom into an `Input`, sends it to the Nexus as `Call.{ Caller Input }` with the
  caller from the connection's peer credentials, and writes each `Output` back as a datom line. A CLI
  called with no datom prints the Ethos of the Signal.
- **An emission that runs a program.** `Run` is attempted by the Nexus as the emission `Command`, sent
  with `EmissionSocket::send`; the translator's body, `Emittable<RelayTranslator> for Command`, is the
  words of the call and one use of `capture`; the outcome `Finished` (`Done` with what the program wrote,
  or `Refused` with its status) is the answer. With no translator listening, the answer is `Unobserved`,
  `Unsubmitted`.
- **A lasting emission.** `Follow` is held open by the Nexus (`EmissionSocket::hold`); the translator's
  body, `Lasting<RelayTranslator> for Follow`, is a `Growth`, which waits for a file not yet written in
  its nearest existing ancestor, and gives an outcome `Lines` each time the file grows, until the Nexus
  closes the connection. The Nexus remembers each line as it comes.
- **The hook socket.** The harness's payload, here a line `Started alpha`, is read into a `Hook` by
  `Translatable<RelayTranslator> for Hook` and sent to the Nexus as `Report`; `relay-hook`, run by the
  harness, ends with 0 whatever happened.

`relay-translator/tests/relay.rs` runs the Nexus and its translator in one process and exercises all of
it, with the failures: unreadable text, no translator, no Nexus.

The Relay Nexus keeps its memory in the process and holds no processes of the process library: it shows
the translator library, and the library's connection to the process manager is the experiment's, which
takes both.

## Building

Cargo is not run here; `Cargo.lock` and `Cargo.nix` are made on the builder with build-base's toolchain
and crate2nix, and the gate is the flake's `checks.x86_64-linux.default`:

```sh
nix run github:Mic92/nix-fast-build -- --remote <builder> --no-nom --no-download \
  --eval-workers 1 --flake 'git+file://<clone>?rev=<commit>#checks.x86_64-linux'
```
